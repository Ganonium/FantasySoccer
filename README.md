# FantasySoccer

Mobiles Fußball-Billard-Spiel für Android (Hochformat): 3 vs. 3 Spielerkreise, Steuerung wie
Billard – Spieler antippen, zurückziehen, loslassen.

## Inhalt

- [`prototype/kickball.html`](prototype/kickball.html) – ursprünglicher Single-File-Prototyp
- [`docs/HANDOVER.md`](docs/HANDOVER.md) – Projekt-Übergabe aus Claude Chat
- [`docs/REVIEW.md`](docs/REVIEW.md) – Code-Review des Prototyps: Bugs und Verbesserungsideen

## Prototyp starten

```bash
python3 -m http.server 8080 --directory prototype
# Browser / Android: http://<PC-IP>:8080/kickball.html
```
